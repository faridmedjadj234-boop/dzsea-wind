# DzSea Wind

موقع ويب ثابت لتوقعات الرياح والأمواج على الساحل الجزائري، يعمل من المتصفح ولا يحتاج إلى APK.

## الملفات
- `index.html`: بنية الصفحة.
- `style.css`: التصميم المتجاوب للهاتف والكمبيوتر.
- `app.js`: الخريطة، المدن، وجلب بيانات الطقس والبحر.

## النشر مجانًا عبر GitHub Pages من الهاتف
1. افتح https://github.com وسجّل الدخول أو أنشئ حسابًا.
2. أنشئ مستودعًا جديدًا باسم `dzsea-wind`.
3. اجعله `Public`، ثم اضغط `Create repository`.
4. افتح المستودع واضغط `Add file` ثم `Upload files`.
5. ارفع الملفات الثلاثة الموجودة في هذا المجلد: `index.html`, `style.css`, `app.js`، ثم اضغط `Commit changes`.
6. افتح `Settings` ثم `Pages`.
7. في `Build and deployment` اختر `Deploy from a branch`.
8. اختر الفرع `main` والمجلد `/(root)` ثم اضغط `Save`.
9. انتظر اكتمال النشر. سيظهر رابط شبيه بـ `https://USERNAME.github.io/dzsea-wind/`، حيث تستبدل USERNAME باسم حسابك.
10. افتح الرابط من Chrome على هاتفك. لإضافة اختصار: قائمة Chrome ⋮ ثم `Add to Home screen` أو `Install app` إن ظهرت.

## ملاحظات
- يحتاج الموقع إلى اتصال إنترنت؛ الخريطة وبيانات الطقس تأتي من خدمات خارجية.
- يستخدم Leaflet وOpenStreetMap وواجهات Open-Meteo العامة. قد تتغير شروط الاستخدام أو حدود الطلبات.
- بيانات الأمواج توقعات نموذجية وليست قياسات مباشرة. لا تعتمد عليها وحدها لقرار الصيد أو الإبحار.
- GitHub Pages يستضيف ملفات ثابتة؛ لا توجد مفاتيح API سرية في هذا المشروع.
